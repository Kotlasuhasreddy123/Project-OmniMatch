# Reporting a security issue

Please report suspected vulnerabilities privately to suhasreddykotla222@gmail.com. Include the affected version, a short description and safe reproduction steps. Do not include credentials, recordings or patient information. Use fictional examples only.

See [installed guardrails and deployment prerequisites](docs/SECURITY_GUARDRAILS.md) and the [incident response procedure](docs/SECURITY_RESPONSE.md). The project does not claim independent security certification or suitability for real patient care. Keep dependencies, the host operating system and Docker updated.
